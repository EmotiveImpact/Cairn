title: "Review before you remove"
description: "Choose a target, inspect candidates, and approve only what you understand."
---

**Make room** starts with a final available-space target. Cairn compares that target with the current reading and presents eligible options from a completed internal scan for individual review. A target is a planning aid, not a promise that a particular action will free that amount.

## Before approving an item

1. Read its exact path and estimated size.
2. Check its requirements and whether the data can be rebuilt.
3. Check the selected scope and destination.
4. Confirm the action only if you want that specific change.

Build output and tool caches often have different consequences from repositories, saved sessions, or credentials. If rebuildability is uncertain, review is required.

## What the space number means

Moving an item to Trash does not immediately increase available capacity. Cairn records the action separately from any later capacity observation. The available-space target is met only when a new reading shows it has been met.

Cairn does not run unattended cleanup as part of this journey.
