Cairn is a Mac cleaner being built for developers. It helps you understand what is using space, review potential cleanup items, and keep known working locations in place.

**Cairn is in development.** These pages explain the current product direction and local implementation. There is no public download yet. Screenshots on the website use labelled sample data.

## The short version

1. **Understand** available space and dated changes in Overview and Changes.
2. **Review** exact paths, sizes, and requirements before approving an action.
3. **Protect** known source-control, coding-session, credential, and recovery locations.
4. **Check the outcome** in Activity & Recovery and with a new available-space reading.
